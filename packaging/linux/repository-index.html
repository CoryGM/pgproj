pgproj package repositories

Signed apt and dnf repositories for pgproj, a PostgreSQL database project compiler: amd64/x86_64 and arm64/aarch64. The packages are self-contained; they need only the system libraries they declare.

Debian and Ubuntu (apt)

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL @URL@/pgproj.asc | sudo tee /etc/apt/keyrings/pgproj.asc >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/pgproj.asc] @URL@/apt stable main" | sudo tee /etc/apt/sources.list.d/pgproj.list
sudo apt update && sudo apt install pgproj

Fedora, RHEL, and other dnf systems

sudo curl -fsSL -o /etc/yum.repos.d/pgproj.repo @URL@/pgproj.repo
sudo dnf install pgproj

dnf asks to import the key the first time; it is the one below.

Release candidates

The testing channel holds the newest release candidate, when there is one newer than the latest release. Add it beside stable: for apt, a second line ending in testing main; for dnf, @URL@/pgproj-testing.repo.

The signing key

The repositories' metadata and the .rpm packages are signed with pgproj.asc. Its fingerprint is in the project's repository and on each release page. The same packages, and every other build, are on the GitHub releases, with checksums and build provenance.
