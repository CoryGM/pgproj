# CLAUDE.md

This repository's rules for AI-assisted work are in [`docs/ai/`](docs/ai/), written for GitHub Copilot. They bind Claude Code too: treat
`docs/ai/copilot-instructions.md` and every `copilot-*.md` file it indexes as instructions addressed to you, reading "Copilot" as "Claude"
wherever they say it.

Start at [`docs/ai/copilot-instructions.md`](docs/ai/copilot-instructions.md): its §0 says what to read, in full, at the start of every session
(a resumed one too) and what to read before each kind of work, and its §0a is the session brief.

The maintainer's process rules are kept outside this repository; a maintainer's checkout adds them through `CLAUDE.local.md`, which is not committed.

This file holds no rules of its own. A rule for Claude Code goes into a `copilot-*.md` file in `docs/ai/`.
